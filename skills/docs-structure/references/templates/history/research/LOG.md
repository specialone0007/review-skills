One file per month under `log/`. An entry is written once, in the current month's file; this
document lists the months, newest first, with one line on what each holds. The checker fails
when a month file is not linked from here.

The test for an entry: if it would not appear in, or shape, something we publish, it does
not go here. How a tool was built belongs in the commit and its PR.
