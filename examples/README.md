## A note on what these show

These were generated by pointing each skill at this repository and committing the result unedited. The findings in them are real. The previous set led to a missing UTF-8 guard in a bundled script, a README claim that did not match CI, and a missing `## Related Skills` section, all fixed in the change that published them.

This set found more. `feature-audit` reproduced a credential leak — a git remote URL is printed unredacted whenever the host's top-level domain is not `.com`, `.org` or `.io` — and demonstrated that the collection's one write path overwrites existing files without asking. `test-gap-audit` found a snapshot whose own comment says it pins a reversibility proof while it actually pins a refusal. None of those were known before the run.

That is the point of publishing them: a report you can check beats a report that reads well. The corollary is that a published report is only honest while it is current, so these are regenerated whenever the skills or the repository change enough to move the findings.

## Regenerating them

Re-run each skill against a clean checkout and replace the file wholesale. Do not edit a report's citations by hand — a report that has been touched up is no longer evidence of what the skill produces, which is the only thing these files are for.
